# 工业设备故障案例知识库

本文档记录盾构机及类似工业设备的典型故障模式、故障现象、可能原因、相关传感器、建议检查项和处理建议。

---

## F001 推进速度下降且刀盘转矩升高

### 故障现象

设备运行过程中，推进速度 TJSD 持续下降，同时刀盘转矩 DP_ZJ 持续升高，总推进力 TJL 也可能同步升高。

### 可能原因

1. 掌子面土体阻力增大，导致刀盘切削负载增加。
2. 刀具磨损或局部卡滞，使刀盘转矩升高。
3. 推进速度、刀盘转速和总推进力之间参数匹配不合理。
4. 开挖仓压力偏高，造成开挖阻力增大。
5. 泥饼形成或渣土排出不畅。

### 相关传感器

- TJSD：推进速度
- TJL：总推进力
- DP_ZJ：刀盘转矩
- DP_SD：刀盘转速
- KWC_PRS：开挖仓压力
- PJGL_FLOW：排浆管路流量

### 建议检查项

- 检查刀盘转矩是否持续升高。
- 检查推进速度是否连续下降。
- 检查总推进力是否同步升高。
- 检查开挖仓压力是否异常升高。
- 检查排浆管路流量是否下降。
- 检查刀具磨损和刀盘卡滞情况。

### 处理建议

适当降低推进速度，检查刀盘负载和刀具状态；若开挖仓压力偏高，应检查排浆系统是否通畅，并调整泥水循环参数。

## F002 开挖仓压力异常升高

### 故障现象

开挖仓压力 KWC_PRS 持续高于正常范围，可能伴随刀盘转矩升高、推进速度下降和排浆流量下降。

### 可能原因

1. 排浆管路堵塞或排浆不畅。
2. 进排浆流量不平衡。
3. 推进参数过大导致开挖仓内土体积聚。
4. 掌子面地层突变，开挖阻力增大。
5. 压力传感器异常或标定偏差。

### 相关传感器

- KWC_PRS：开挖仓压力
- PJGL_FLOW：排浆管路流量
- TJSD：推进速度
- TJL：总推进力
- DP_ZJ：刀盘转矩

### 建议检查项

- 检查排浆流量是否明显下降。
- 检查进浆和排浆是否平衡。
- 检查推进速度是否过高。
- 检查压力传感器是否存在异常。
- 检查开挖仓是否存在积渣或堵塞。

### 处理建议

优先检查泥水循环和排浆管路状态，必要时降低推进速度并调整进排浆参数，避免仓压持续异常升高。

## F003 注浆量异常不足

### 故障现象

同步注浆过程中，注浆累计量 ZJL_LJ 低于预期范围，可能伴随注浆压力波动或注浆流量不足。

### 可能原因

1. 注浆泵工作异常。
2. 注浆管路堵塞。
3. 浆液供应不足。
4. 注浆参数设置不合理。
5. 管片背后空隙估计偏差。

### 相关传感器

- ZJL_LJ：注浆累计量
- 注浆压力
- 注浆流量
- 推进环号

### 建议检查项

- 检查注浆泵运行状态。
- 检查注浆管路是否堵塞。
- 检查浆液供应是否稳定。
- 检查注浆量是否与当前环号和地层条件匹配。

### 处理建议

检查注浆泵和管路状态，必要时调整注浆压力和注浆量，确保管片背后空隙充分填充。

---

## F004 排浆流量下降且仓压波动

### 故障现象

排浆管路流量 PJGL_FLOW 明显下降，同时开挖仓压力 KWC_PRS 出现波动，可能伴随刀盘转矩升高。

### 可能原因

1. 排浆管路局部堵塞。
2. 渣土颗粒沉积导致输送不畅。
3. 泥水循环系统参数异常。
4. 开挖仓内渣土积聚。
5. 管路泵送能力下降。

### 相关传感器

- PJGL_FLOW：排浆管路流量
- KWC_PRS：开挖仓压力
- DP_ZJ：刀盘转矩
- TJSD：推进速度

### 建议检查项

- 检查排浆管路是否堵塞。
- 检查排浆泵运行状态。
- 检查开挖仓压力波动幅度。
- 检查刀盘转矩是否同步升高。
- 检查泥水循环参数是否合理。

### 处理建议

检查排浆管路和泥水循环系统，必要时降低推进速度并清理管路，防止仓压持续波动影响开挖面稳定。
