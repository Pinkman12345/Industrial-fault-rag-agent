# 工业设备故障诊断报告

- 生成时间：2026-05-04 21:06:29
- 用户问题：推进速度下降，同时刀盘转矩升高，可能是什么原因？

## 一、RAG 诊断回答

## 1. 故障现象概括
推进速度下降，同时刀盘转矩和总推进力升高，说明设备掘进负载可能增大。

## 2. 可能原因分析
可能与掌子面阻力增大、刀具磨损、排浆不畅或仓压异常有关。

## 二、规则工具判断结果

- 是否命中异常模式：True
- 判断摘要：共命中 3 条异常规则，建议结合 RAG 检索结果和时序趋势进一步确认。

### 命中规则

#### R001 推进速度下降且刀盘转矩升高

- 可能模式：掘进阻力增大 / 刀盘负载异常
- 判断依据：推进速度下降同时刀盘转矩升高，通常说明单位推进过程中的切削阻力增加。
- 关联故障：掌子面阻力增大, 刀具磨损, 刀盘局部卡滞, 泥饼形成

#### R002 推进负载整体升高

- 可能模式：掌子面阻力增大 / 地层突变 / 盾体受阻
- 判断依据：推进速度下降而总推进力和刀盘转矩同时升高，说明设备为维持掘进需要更高负载。
- 关联故障：地层阻力增大, 盾体卡滞, 刀具磨损, 推进参数不匹配

#### R003 仓压升高且排浆流量下降

- 可能模式：排浆不畅 / 泥水循环异常
- 判断依据：开挖仓压力升高同时排浆流量下降，可能表示排浆管路堵塞或渣土输送不畅。
- 关联故障：排浆管路堵塞, 开挖仓积渣, 泥水循环异常
