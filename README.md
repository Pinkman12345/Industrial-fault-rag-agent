# 工业设备故障溯源 RAG-Agent 系统

本项目是一个面向工业设备/盾构机故障诊断场景的 RAG-Agent 系统，结合本地知识库检索、大模型结构化抽取、规则判断工具、CSV 趋势分析与 Markdown 报告生成，实现从自然语言故障描述到结构化诊断报告的完整流程。

项目主要用于展示 LLM 应用开发、RAG、Agent 工具调用、结构化输出、Prompt Engineering 与工业故障诊断场景结合的工程能力。

---

## 一、项目功能

系统支持以下能力：

- 基于本地 Markdown 知识库的故障问答；
- 从自然语言故障描述中抽取传感器状态；
- 使用 LLM JSON 结构化抽取识别 TJSD、DP_ZJ、TJL 等工业变量状态；
- 提供关键词规则 fallback，提升系统稳定性；
- 调用传感器解释工具，展示变量含义、所属系统和关联故障；
- 调用异常规则判断工具，识别典型异常模式；
- 调用 CSV 趋势分析工具，分析传感器时序变化；
- 结合 RAG、规则结果和趋势分析，自动生成 Markdown 诊断报告；
- 提供 Streamlit 前端页面，支持交互式故障诊断。

---

## 二、系统架构

整体流程如下：

```text
用户故障描述
    ↓
LLM JSON 状态抽取
    ↓
关键词规则 fallback
    ↓
传感器解释工具
    ↓
异常规则判断工具
    ↓
CSV 趋势分析工具
    ↓
RAG 知识库检索
    ↓
Agent 结果整合
    ↓
Markdown 结构化诊断报告
