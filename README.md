# 工业设备故障溯源 RAG-Agent 系统

本项目是一个面向工业设备/盾构机场景的 **RAG-Agent**，用于验证大模型在工业设备故障问答、故障原因分析、传感器解释、异常规则判断、时序数据辅助分析和诊断报告生成中的应用流程。

项目采用本地工业知识文档作为知识库，结合 Chroma 向量检索、OpenAI 兼容大模型 API、规则判断工具和 Streamlit 可视化页面，实现一个可运行、可展示、可扩展的工业故障辅助诊断原型。

---

## 1. 项目背景

在盾构机、掘进装备和复杂工业设备运行过程中，传感器变量之间存在较强耦合关系。例如，推进速度、总推进力、刀盘转矩、开挖仓压力和排浆流量之间往往会共同反映设备负载、地层阻力、排浆状态和刀盘切削状态。

传统故障分析通常依赖人工经验、阈值规则或单一传感器判断，存在以下问题：

- 多源传感器变量含义复杂，人工排查成本较高；
- 故障现象和可能原因之间往往不是一一对应关系；
- 单纯依赖大模型回答容易出现幻觉；
- 普通 RAG 问答缺少工具调用和结构化报告能力；
- 工业诊断场景需要可复核的知识依据、规则依据和数据侧证据。

因此，本项目尝试构建一个轻量级 **工业设备故障溯源 RAG-Agent**，将本地知识库检索、大模型结构化回答、传感器解释工具、异常规则工具和 CSV 趋势分析工具结合起来，生成辅助诊断报告。
